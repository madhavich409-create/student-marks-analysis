# Student Marks Analysis 📊

A simple Python project that analyzes student marks using Pandas and NumPy.

## Features

- Displays student marks
- Calculates average marks
- Finds highest marks
- Finds lowest marks
- Displays students who passed

## Technologies Used

- Python
- Pandas
- NumPy

## How to Run

1. Open `marks_analysis.py`
2. Run the program using Python
3. View the student marks and analysis results
